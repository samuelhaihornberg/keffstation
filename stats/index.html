Comment ces chiffres sont-ils produits ?

  • Chaque page visitée enregistre une vue, la durée passée dessus et chaque clic sur un lien ou un bouton (compteur en direct dans la barre du navigateur).
  • Les mesures sont stockées localement (localStorage) : elles reflètent ta navigation sur ce navigateur, et une base de référence est versionnée dans le dépôt.
  • Un export JSON permet de consolider plusieurs navigateurs : importe le fichier sur l'autre poste pour fusionner les totaux.
  • Les mêmes événements sont envoyés à Google Analytics quand le tag est présent sur la page.
