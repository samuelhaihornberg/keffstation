# Agent produit et médias — procédure

## Périmètre
Pour chaque modèle exact : caractéristiques, prix (boutique officielle), 3 à 5 images, 1 à 2 vidéos, conditions d’usage des médias. Les médias restent dans la fiche de leur modèle.

## Sources
1. Boutique ou site officiel du fabricant (modèle, référence, prix, caractéristiques, accessoires, dossier de presse).
2. Bibliothèques libres (Wikimedia Commons, Flickr sous licence vérifiée), Google Images / Google Vidéos / YouTube / réseaux pour découvrir des pistes.
3. Chaque média est évalué sur sa page d’origine, jamais sur un résultat de recherche seul.

## Mots-clés
Nom exact, référence, marque, puis : « libre de droits », « royalty-free », « usage commercial autorisé », « CC0 », « CC BY », « CC BY-SA », « public domain ».

## Statuts (un seul par média)
- `droits_verifies` : la source établit une autorisation compatible avec la vente en boutique (licence ouverte ou écrite), avec URL, auteur, date.
- `declare_libre_par_source` : la source affiche « libre de droits » (texte mot pour mot, URL, date). Non intégré tant que l’auteur/éditeur, les conditions commerciales, l’attribution et les modifications ne sont pas confirmés. Statut non suffisant pour publier seul.
- `a_verifier` : pertinence ou droits non établis.
- `rejete` : ne représente pas le modèle exact, ou droits refusés/non compatibles.

## Données enregistrées par média
URL d’origine · mention de droits mot pour mot · licence ou conditions · auteur ou éditeur · qui peut autoriser l’usage · usage commercial (boutique, intégration, téléchargement) · attribution requise · modifications autorisées · correspondance au modèle exact · date de vérification · statut.

## Règle d’intégration
Seuls les médias `droits_verifies` sont intégrés. Les autres restent dans le registre, sans publication.
