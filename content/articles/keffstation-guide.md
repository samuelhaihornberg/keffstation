# KeffStation: Guide complet de la vitrine smart tech

## Introduction

KeffStation est une vitrine web animée présentant les applications et projets du réseau samuelhaihornberg.github.io. La plateforme regroupe plusieurs catégories d'applications et de services technologiques.

## Structure du site

Le site se compose de plusieurs sous-projets :

1. **KiffTech** - Agent IA veille technologique, suivi des prix officiels et des réseaux sociaux
2. **ViArtificial Labs** - Moteurs COS, langage de connexion, bots et IA locale
3. **Tricktrocjob** - Échange d'astuces, troc d'objets, services entre particuliers
4. **Videogames** - Jeux rétro, émulation, configurations, roms
5. **Linguistic Motors** - (À explorer)
6. **cos-editor** - Éditeur de syntaxe COS avec analyse locale, aperçu et export

## Accès direct

Toutes les catégories sont accessibles depuis la page d'accueil :
- `https://samuelhaihornberg.github.io/keffstation/`
- `https://samuelhaihornberg.github.io/keffstation/kifftech/`
- `https://samuelhaihornberg.github.io/keffstation/viartificial-labs/`
- et les autres sous-dossiers

## Fonctionnalités clés

- **Vitrine ronde animée** : affichage dynamique des applications
- **Recherche par catégories** : filtrage par type d'application
- **Recherche par tags** : mots-clés associés à chaque application
- **Export et partage** : options d'export JSON et partage social

## Pour les développeurs

- Documentation COS disponible dans `viartificial-labs/src/cos-langage.js`
- Éditeur COS: `cos-editor/` avec analyse locale et export JSON
- Tous les projets sont open source et hébergés sur GitHub Pages
