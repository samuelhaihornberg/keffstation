# KeffStation: Complete guide to the smart tech showcase

## Introduction

KeffStation is an animated web showcase presenting the applications and projects of the samuelhaihornberg.github.io network. The platform brings together several categories of applications and technology services.

## Site structure

The site is composed of several sub-projects:

1. **KiffTech** - AI agent for technology monitoring, official price tracking and social networks
2. **ViArtificial Labs** - COS engines, connection language, bots and local AI
3. **Tricktrocjob** - Tip exchange, object bartering, peer-to-peer services
4. **Videogames** - Retro games, emulation, configurations, roms
5. **Linguistic Motors** - (To explore)
6. **cos-editor** - COS syntax editor with local analysis, preview and export

## Direct access

All categories are accessible from the home page:
- `https://samuelhaihornberg.github.io/keffstation/`
- `https://samuelhaihornberg.github.io/keffstation/kifftech/`
- `https://samuelhaihornberg.github.io/keffstation/viartificial-labs/`
- and other subfolders

## Key features

- **Animated round showcase**: dynamic display of applications
- **Category search**: filtering by application type
- **Tag search**: keywords associated with each application
- **Export and share**: JSON export and social sharing options

## For developers

- COS documentation available in `viartificial-labs/src/cos-langage.js`
- COS Editor: `cos-editor/` with local analysis and JSON export
- All projects are open source and hosted on GitHub Pages
